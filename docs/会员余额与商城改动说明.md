会员订单页面的显示标识为 `memberOrders`，后端实际资源为 `shopOrder`。原页面配置未指定接口资源，列表请求错误地发往 `/api/gym-management-system/memberOrders/v1/page`，返回404。已在会员订单配置中明确 `api: 'shopOrder'`，列表、筛选、刷新与详情统一使用正确接口。

本次修改四个文件：`frontend/src/resources.ts` 补齐会员订单接口配置；`frontend/tests/fixtures.ts` 对不存在的接口返回404，避免模拟接口掩盖真实地址错误；`frontend/tests/commerce.spec.ts` 补测本人订单加载、筛选、刷新、详情及无订单空列表；本文件补充修复报备。前端更新后刷新页面生效。

## 已实现的行为

- 会员卡类型仅支持 `1 月卡、2 季卡、3 年卡、4 次卡`。四种卡均有余额，可以充值和扣费；次卡另保留次数核销。
- 修复原扣费分支语法错误，以及编辑月卡、季卡、年卡和次卡时清空余额的问题。编辑资料不写余额，余额通过充值、扣费和购物结算调整；卡所属会员不可改，有余额的卡不可删除。
- 办卡初始充值、后续充值、余额消费和次数核销均记录流水。保存操作时间、会员和卡号快照、金额、前后余额、核销前后次数、操作人及角色、备注、关联订单。
- 管理员可查看全部会员的卡、充值流水、消费记录与订单。会员只能查看自己的卡、流水和订单；分页条件和详情都在后端校验归属。流水没有修改、删除接口。
- 充值、手工扣费和核销由管理员操作。会员账号不能直接增加余额，购物则从本人正常且已生效的会员卡扣款。
- 管理员可新增和编辑商品、调整可售/可租库存、上下架商品；会员按分类和名称查找商品，选择自己的会员卡直接结算。
- 支持储物柜和充电宝租用，以及饮料、蛋白粉、运动周边购买。租用品价格为元/件/天，租期为 1–30 天，租金预付；管理员确认物品已实际归还后释放库存，预付租金不退。订单保存应归还与实际归还时间。
- 购物价格由后端读取数据库计算，忽略客户端报价。订单、库存、余额和流水一起提交或回滚。同一卡加行锁，防止并发透支；商品加行锁，避免超售；结算标识防止同次提交重复扣款。归还重复确认只释放一次库存。
- 商品编辑携带原库存，库存已变化时拒绝覆盖，提示刷新。商品分类建好后不可修改；下架保留商品及历史订单，仍可归还在租物品。

## 数据库升级

已有数据库先备份，执行 [upgrade_wallet_shop.sql](../sql/upgrade_wallet_shop.sql)，再重启前后端。这个升级脚本保留已有表与业务数据，将空余额补为 0，并新增 `card_transaction`、`shop_product`、`shop_order` 三张表；商品表为空时加入五种示例商品，价格与库存可在商品管理页面调整。

首次安装仍执行 [init.sql](../sql/init.sql)，已包含新表与示例商品。`init.sql` 会重建表，不用于已有数据库升级。

旧类型 `5` 的卡与余额会保留，管理员需要按实际权益改成 1–4，并填写对应有效期或次数，才可继续充值和结算。历史余额保留；升级前的充值和扣费缺少原始记录，无法恢复历史流水，从新操作开始记录。

## 接口

前缀为 `/api/gym-management-system`，请求头沿用 `token`。

| 接口 | 方法 | 权限/说明 |
|---|---|---|
| `/membershipCard/v1/recharge` | POST | 管理员；`id, amount, remark` |
| `/membershipCard/v1/consume` | POST | 管理员；`id, amount` 或 `id, count`，可带备注 |
| `/membershipCard/v1/page`、`/detail` | POST、GET | 管理员全部；会员本人 |
| `/cardTransaction/v1/page` | POST | 管理员全部；会员本人；`type=1充值/2余额消费/3次数核销`，可按卡、会员和时间范围筛选 |
| `/cardTransaction/v1/detail?id=…` | GET | 管理员或记录所属会员 |
| `/product/v1/page` | POST | 登录可查；会员只能查上架商品 |
| `/product/v1/save`、`/update` | POST | 管理员；修改须携带 `expectedStock` |
| `/product/v1/delete?id=…` | DELETE | 管理员；执行下架，保留记录 |
| `/shopOrder/v1/checkout` | POST | 会员；`productId, cardId, quantity, rentalDays, requestNo`；重试保持同一标识 |
| `/shopOrder/v1/page`、`/detail` | POST、GET | 管理员全部；会员本人 |
| `/shopOrder/v1/returnRental?id=…` | POST | 管理员实际验收后确认归还 |
